# Prospecção SC

App web para encontrar empresas de Santa Catarina no Google Maps e organizar os contatos (funciona no celular e no notebook, instalável como app).

- Abra o app pelo GitHub Pages e cole sua chave da Places API (New) em **Ajustes**. A chave fica salva só no seu aparelho, nunca neste repositório.
- Restrinja a chave no Google Cloud ao endereço do app (`https://djonyscj-max.github.io/*`) e só à Places API (New).
